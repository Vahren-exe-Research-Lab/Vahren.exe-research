### 16H — count-gated NULL slot call is conditional, not an observed crash
**ID:** `REA-LOCAL-20261029-16H-P0-OGG-NULLSLOT-LOOP-GATE-STATIC-01`.

If count>0, `0x005DF6F2` reads mode from `+0x520`, `0x005DF717` calls slot `+0x14`; only if this call returns does `0x005DF788` call slot `+0x18`.

Thus if a caller reaches this function with positive count and mode0, the native slot data implies a NULL first target. **But:** `0x005DEDF0` lacks a demonstrated caller of mapping table slot `+0x0C`; mode0 plus count>0 plus reachable outer function are **three separate unmet run-time conditions**.

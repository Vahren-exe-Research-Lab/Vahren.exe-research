## Native instruction anchors, significance, source correction order

- **06H:** `0x00502100` WAVEFORMATEX builder computes blockAlign and average byte rate; `0x00502260/0x00502269` copies nAvgBytesPerSec to DirectSound buffer size `stream+0x28` (= N). Prior 05H worker H=`floor(N/2)` then Lock `(0,H)` or `(H,2H)`. Ordinary PCM N≈1-second bytes, H≈half-second; odd N can yield split pointer lengths. This does **not** prove any driver returns a second region, nor that its content survives an untouched Unlock. The 06H original audit first failed an off-by-one instruction address (61/62), corrected to 62/62; do not hide that history.

- **07H:** `0x00502111/0x00502125` stores channel/bits fields as low16 while `0x00502130/0x00502136/0x0050213D/0x00502147` multiplies raw32 then stores low16 blockAlign; `0x00502143/0x0050214D` multiplies truncated blockAlign by raw32 rate modulo2^32. Synthetic 1Hz/1bit or high-word bits examples show arithmetic boundaries, **not a valid Ogg gameplay input**.

- **08H — correction of 07H synthetic reach:** in successful OggLoader `0x00502071 MOV [ESI+0x110],0x10` fixes bits/sample=16; `0x0050206B/0x0050207F` populate channels/rate, ready `+5=1` only after success. Consequently 07H's 1-bit and raw high-word-bit synthetic examples **are not reachable via this identified normal loader path**. Other writers/aliasing remain VERIFY. A *real* odd sample rate can still create a half-buffer not PCM-frame aligned.

- **09H:** `0x005D3F60` Vorbis identification parser accepts type1/signature, reads channels at `0x005D3F92`, rate at `0x005D3F9D`, and checks signed `channels>=1`, `sampleRate>=1` at `0x005D3FED/0x005D3FF2`. No parity rejection seen *there*; 11,025 Hz **not rejected by this isolated header gate**, but full decode/DS buffer validity remains untested.

- **10H:** when 16-bit frameBytes=2*C and odd-rate H=N/2 is not a frame multiple, Vorbis `0x005D1039..0x005D1046` integer division and `0x005D105B` -131 branch can occur if remaining request < frameBytes and PCM is otherwise available. Upper `0x00501FC2 ADD EDI,ESI` subtracts 131 from accumulated output and can request/rewrite a previous interval. A **synthetic model** demonstrates conditional revisit, not actual audible corruption or actual Lock success.

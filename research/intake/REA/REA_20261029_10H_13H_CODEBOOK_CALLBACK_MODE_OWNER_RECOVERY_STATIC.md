### 11H — index-vs-original-symbol codebook decoder ABI
**ID:** `REA-LOCAL-20261029-11H-P0-OGG-CODEBOOK-SYMBOL-BITCURSOR-STATIC-01`.
- `0x005DA070` stores sorted-code thresholds in entry`+0x14`, original symbol map in `+0x18`, code lengths in `+0x1C`, fast table in `+0x20`, peek width in `+0x24` and fallback width in `+0x28`. The `0x005DA930` lower decoder peeks bits via `0x005DA94A -> 0x005E6CF0`, fast consumes them via `0x005DA982 -> 0x005E6DB0`, and slow path compares reversed codes against sorted thresholds; on insufficient bits returns -1.

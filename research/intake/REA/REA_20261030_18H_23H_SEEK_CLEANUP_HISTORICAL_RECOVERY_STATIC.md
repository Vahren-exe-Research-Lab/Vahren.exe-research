Both hard-error `-128` and EOF `-2` can lead to shared seek-position conversion at `0x005D0D89` (`fldz`, `__allshr 0x005D1C50`, `__allshl 0x005D1C30`), loop frame consume/page update `0x005D0E17/0x005D0E43`, fallback total at `0x005D0E52`. Returning 0 requires actual position target attained. Don't assume recover/success on all failures.

- 19H **narrows 14H hypothesis**: `0x005CFF10(this,-1)` normally aggregates 64-bit per-link length (recursive `0x005CFF52`, ADD/ADC `0x005CFF5A/5C`), but checks state `+0x58>=2`, link mode `+4` and count `+0x34`. The `0x005D04E0` early path checks aggregate/link/state as well. A later unvalidated `-131` sentinel store is structurally possible, but not demonstrated under stable valid link state without concurrent mutation, malformed count, overflow or aliases.

- 20H **direct write scope, not whole-program proof**: limited native scan of `0x005CFA10` detects local state writes `+0x58` at `0x005CFA6D`=4, `0x005CFBA2`=EDI(2), `0x005CFC16`=3; `0x005CF010` at `0x005CF07A`=2, `0x005CF160`=3, `0x005CF20A`=2.

# ご自身で開始する原作戦闘記録ツール
更新：2026-10-22 Stage10。原作Vahren.exe専用・読取専用。現行は採取器v7。
開いている記録ツールはいったん閉じ、同じショートカットから再度開いてください。タイトルの「採取器v7」が更新確認になります。ゲーム自体は閉じなくて構いません。
Task一覧の空きスロットは原作で許可されているため、v7は位置を保って記録し、空きポインタを読みません。Unit/Troopなどの破損検査はそのままです。
今回の失敗3件は途中バイトから構造を回収済みです。今すぐ同じ戦闘をやり直す必要はありません。詳細は BATTLE_TAKEOVER_RESEARCH_STAGE10_20261022.md。

## 開き方
デスクトップの「迫真戦記 戦闘記録」をダブルクリックします。
見つからない場合は、この研究フォルダ内の START_BATTLE_RECORDER.cmd をダブルクリックします。
画面を開いただけでは記録は始まりません。

## 使い方
1. 原作 Vahren.exe を起動し、戦略画面で攻撃できる状態にします。
2. ツールの「記録開始」を押します。PIDは自動で調べます。
3. 緑色の「開始待ち：攻撃して大丈夫です」が出たらゲームへ戻り、侵攻します。
4. 戦闘画面に入り、できれば10秒程度はすぐに決着させず、その後は通常どおり進めてください。
5. 戦略画面へ戻ると約5秒後に記録を終了します。「今回の結果を開く」で保存結果を確認できます。
最大記録時間は開始から20分。停止したいときは「記録終了（ゲームは続行）」を押します。
このボタンもウィンドウを閉じる操作も、ゲーム自体を止めません。

## 表示の意味
- 開始待ち：原作EXEの照合と広いメモリ領域の事前読取に成功し、遷移を記録中。
- 採取成功：攻撃表・援軍・陣営・Unit・Troop・Task構造を保存し、構造検査に合格。
- 詳細採取に失敗：途中まで取得した生データと原因を保存。同じ原因3回で詳細採取を停止。
- 記録終了：今回のSUMMARYと時系列EVENTSを保存済み。成功0件なら完全な戦闘情報は未採取です。
採取成功でも、実MAP・HP/MP・スキル・RNG・VMの完全な開始パケットや戦闘置換成功を意味しません。

## 保存先と注意
保存先はこのsearch_indexフォルダ。BATTLE_USER_時刻_識別子_SUMMARY.jsonが今回の結果です。
生データはRAW、失敗はFAILURE、時系列はEVENTSという名前です。過去の結果を上書きしません。
原作EXE・セーブに書き込まず、DLL注入・入力操作・プロセス停止も行いません。
別版・改造版・複数のVahren.exeは自動的に選ばず、開始を拒否します。管理者実行や設定変更は不要です。
今回は通常ファイルだけで保存し、ZIPは作りません。

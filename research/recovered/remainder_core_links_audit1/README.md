基準525b37eのreference engineが解決するsource_links/unresolved_citationsを、503symbol/122fieldについて記録した。新しいsource bodyやnativeを取得せず、既存台帳の保存SHAを検査する通常load結果を使う。

明示的source_linksが0のsymbolは319（func220/global46/code47/object5/string1）、fieldは18。未解決section labelを持つのはsymbol102/field23で、前者と重なり得る。W実装ファイル/旧symbols/Codex引継ぎ/曖昧なセッション記号/解析できない節表記も混在する。自動VA言及や別の手動関係の根拠が存在する場合もあるため、『根拠なし』『研究本文未取得』『全て誤り』とは断定しない。

次は未接続の意味ごとに、保存済み一次報告の該当行とその主張を比較してlocator/registry/出典を補う。VAがあるだけの本文を意味の証拠へ昇格しない。既存保留本文や禁止範囲を別wrapperから復元せず、根拠を公開候補へ保持できない場合はその不足を明示する。今回source cell/意味/確度/辞書/関係/コードは変更していない。原作再実験や全出典の意味レビューでもない。

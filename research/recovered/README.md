## 回収と解釈

同名本文がdevelopと現在のopen PR #7〜#19に見つからない資料を回収した。別名の要約や同じ発見が皆無という判定ではない。研究原本の文章を保存したことと、新しく原作x86や実機で裏付けたことは別々に記録する。GitHubへ送信後はコミットとファイルのバイト列を読み戻して確認する。

今後の資料も同じ台帳へ追加し、後日の訂正、未収録の証拠ファイル、ローカルだけの参照を残す。原本の整理は全回収と依存関係の確認後に判断する。

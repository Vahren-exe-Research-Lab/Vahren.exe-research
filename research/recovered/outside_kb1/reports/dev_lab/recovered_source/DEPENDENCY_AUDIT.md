# 疑似C 39関数の依存関係（保存済みGhidra callers/callees 集計）

対象は本sourcebookの manifest.json に含まれる静的VERIFIEDの39関数。Ghidraの取得済みdirect callee配列からの**静的集計**であり、新しいEXE逆解析・外部通信は実施していない。

| 指標 | 件数 |
|---|---:|
| 保存済み疑似Cソース | 39関数 |
| これらの関数が持つ解決済み直接call参照 | 406本 |
| 上記39関数の内部同士の直接call | 63本 |
| **39関数以外への直接call** | **343本** |
| 39関数以外にある異なるcall先アドレス | 173種類 |
| EXTERNAL: 等の別表記で残ったcalleeラベル | 18件 |

**注意**：343は参照本数であって343関数を新しく解析する必要がある意味ではない。173種類も必須の新規ゲーム関数数ではない（CRT/OS/ライブラリを含み得る）。Ghidra未解決のvtable/関数ポインターなどの**間接呼出も未計上**。ゲーム全体のcallgraph網羅度ではない。

## ビルド可能な互換エンジンにする条件

1. 39個のGhidra C風ソースは保全し、実装用ソースにnative引数/メモリ型/呼出規約を明示する。
2. 343本の外部直接参照を分類し、意味不明の状態のまま正規化・stub成功化しない。
3. FPU/x87の丸め、RNG、早期return、状態履歴を限定テストで追跡する。
4. Unit生成、戦略ターン、戦闘update、script VM、UI/audioを再構築し、元EXEの通常プレイ観測で各状態を比較する。

現在の原作実機golden合格は0件、新エンジンstrict MATCHも0件。39/48は重点関数の静的証拠取得であり、EXE全体の解析率やゲーム完成度を意味しない。

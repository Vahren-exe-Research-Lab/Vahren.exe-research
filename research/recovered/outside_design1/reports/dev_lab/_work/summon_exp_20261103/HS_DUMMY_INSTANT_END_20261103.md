# Lv99無抵抗標的：戦闘が即終了する不具合（2026-11-03）

## 現象
- ユーザー報告：新設したLv99無抵抗拠点へ攻め込むと、戦闘が一瞬で終わる。
- 戦闘終了時の結果・敵HP・JOKER技能発動のログは未取得。原因の断定は保留。

## DATから確認できた問題
1. 無抵抗用 `hs_dummy_class : a000` は帝国歩兵のクラス `a000` を継承していた。元の `a000` は `skill = a_zan,g_dash,seiretsu,c_as1` および `skill2 = 1,self_a000` を持つため、派生側の `skill = @` だけでは継承済みの攻撃能力を確実に消せない。設計として無抵抗が保証されていなかった。
2. 標的の設定HPは500,000。一方、原作のJOKER姉貴のLv25習得技能 `sp_jocar` に連なる `sp_jocar_dmg` は `str = fix*999999` の強力な攻撃判定を持つ。命中時に標的が即死する可能性がある。ただし実際に命中したかは未確認。
3. `speed = 1`, `move = 0` は引き続き標的に指定されており、「動かない」という要件と整合する。

## 修正
- `hs_dummy_class : a000` → `hs_dummy_class : base`。ゲームの標準 `base` → `base_kn` の成長・EXP設定は継承し、歩兵の攻撃スキルを継承しない。
- `hs_dummy_class` と `hs_dummy` のHPを500,000 → 5,000,000に変更。
- 標的ユニットとクラスに `brave = 100` を追加。攻撃スキルなし、移動0、Lv99は維持。
- 味方の帝国照術師Lv1、JOKER姉貴Lv25、敵拠点①帝国歩兵Lv5、シナリオ領地接続、経験値設定は変更しない。
- `exp = 0` は再追加しない。

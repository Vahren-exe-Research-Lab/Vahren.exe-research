## 状態の意味

- RECOVERY_RECEIPT_PRESENT: 同じ原本相対パスの回収台帳がある。回収版と現在版の一致は別途SHAで確認する。
- KNOWN_REVIEW_HOLD: 同じパスに既知の保留理由がある。本文取得・別経路での復元をしない。
- DEFERRED_OTHER_OR_PENDING: 容量による次回確認、文字化け、索引・ポインタなど、台帳の理由を確認する。保留解除や不要判定ではない。
- UNREVIEWED_CURRENT_PATH: この比較では回収台帳・個別保留に対応しない。未保存や独立した研究であることは未確定。

GitHubの同じファイル名も候補として併記する。共通名README/INDEX/REPORT/RESULT/HANDOFF/PROGRESSは候補結合から除外し、その他も名前だけの対応と明示する。例は最大3所在、件数は既存固定HEAD目録内の所在数である。本文の同一性・安全性・正式採録の判定には使わない。

次は未確認の場所を担当・研究ID・内容・訂正・SHAで照合し、既存の回収台帳へ採録可能な本文を追加する。原本の整理は全回収と依存関係の確認後とし、本一覧からゴミ箱移動を決めない。

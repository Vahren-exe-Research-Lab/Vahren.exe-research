前回の30行上限だけを理由に残っていた3件を、現行9e7cb388版の辞書と採用済み回収台帳に改めて照合した。既存の研究IDが本文冒頭12行以内の一意な主報告IDと完全一致し、登録VAが同じ保存版に明記される場合だけ、元の出典文字列を残して所在を追記する。意味・型・ABI・実機確認・確度の追加ではない。

5A9CC0、4189B0、49D1B0の3行が対象。49D1B0は別の既引用報告へのリンクを保持した上でもう1主報告へ接続する。元研究・既存REFの限定と後日訂正が優先され、VAの言及だけで辞書の説明全体を証明しない。原本・保留本文・リンク先証拠は取得せず、既存台帳の採用済みMarkdownだけで照合した。

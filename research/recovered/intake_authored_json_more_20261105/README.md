# 関数・メモリ研究のJSON記録を追加

今回選んだ55パスを50本文と5別名として保存した。対象は既存のAI・Unit・勢力・保存・スクリプト関連研究の境界チェックや読戻し記録であり、新しい発見数や今回行った実機試験の数ではない。元JSONの文字列表現と全バイトを保存し、原本SHA・保存版SHA・制約を回収台帳から辿れるようにした。

[第1組](../json_batch4/README.md)・[第2組](../json_batch5/README.md)・[第3組](../json_batch6/README.md)に対象と判断を分けて記録した。既存の取得保留に依存する文書は全体を保留し、別の証拠票から同内容を回収しない。歴史的なPASS・READYやowner書込拒否は元の範囲で扱う。リンク先の原始資料・ログ・ゲーム・スクリプトを取得または実行していない。

[親による全バイト照合](PARENT_BYTES.tsv)と[選択時の目録記録](SELECTED_PATHS.tsv)を参照できる。検索索引へ登録済みの本文は元ファイル名・研究ID・記載されたVAから辿れる。辞書の意味・型・確度への自動昇格はしていない。元文書のゴミ箱移動は行っていない。

同一内容の5組は本文を二重保存せず、各元パスを同じ保存先へ結んだ。台帳の55出典行と50本文を区別する。[既存保留研究に対応する読戻し票3件](DEFERRED_PAIRED_STUDIES.tsv)は元本文を開かず別枠で記録した。別の取得経路による回収はしていない。

従来一覧の外にある候補と作業コピーは、[研究ルートのメタデータ棚卸し](../current_scope_20261105/README.md)へ分けた。139候補・3非祖先HEAD・4作業場所の未コミット変更は今後の照合対象で、収録済みとはしない。

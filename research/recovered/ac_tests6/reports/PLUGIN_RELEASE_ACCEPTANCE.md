## 再生成
WindowsのPowerShellで、`data/recruit_sort_v4`を基準に実行する。
出力先は新しい`dev_lab/_work/<作業名>/`配下を指定する。既存成果物には上書きしない。

```powershell
./tools/build_extensions_candidate.ps1 -OutputDirectory <作業先>/build
python -B ./tests/test_package_extensions.py
python -B ./tools/package_extensions.py <作業先>/build ./README_EXTENSIONS_CANDIDATE.txt <作業先>/candidate.zip
```

ローダー、Core、雇用、選択の4DLLを現行ソースからビルドする。選択は自動準備を有効にし、ローダーと選択の入力分離を一組でビルドする。
包装はビルド記録と4DLLの内容を照合し、固定のファイルだけを取り込む。
原作EXE・DAT・素材・セーブ・ログは収録しない。自作のDAT生成・配置復元ツール4件を固定収録し、原作由来の変更済みDATは利用者側で生成する。

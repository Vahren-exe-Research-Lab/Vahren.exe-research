# 原作ver0.67の手動観測ガイド（新エンジン互換比較用）

目的：新エンジンの完全互換検証に必要な「原作で実際に起きたこと」の証拠を作る。**逆コンパイルの実行ではなく、通常のゲーム操作の観測**である。
研究の原本ZIP、`_REDEV_RESEARCH`配下のMASTER/A〜E/REAおよび設定は編集しない。
ゲーム起動はユーザー本人が判断して行い、管理者権限やWindows保護の無効化は行わない。セキュリティ警告が出たら無理に解除せずスクリーンショットを共有する。

## 1. 原本とは別のゲーム観測用コピーを作る

1. `Win + E` でエクスプローラーを起動する。
2. アドレス欄に `[USER_HOME]\Documents\迫真戦記` と入力して移動する。
3. **`新約迫真戦記―ほのぼの神話ver0.67 豪華版.zip`（画像・音声削除版ではない方）**を探す。
4. 右クリック→「すべて展開」を選び、**`[USER_HOME]\Documents\迫真戦記_観測用`** などの別フォルダへ展開する。
5. コピー側で `Vahren.exe` を探す（ゲームデータはさらに一つ下のフォルダに展開されることもある）。元のZIPの中身は直接編集しない。
6. Windowsに未知の実行ファイル警告が出たら警告内容を確認し、セキュリティを無効化したり「管理者として実行」したりせず、一度作業を止める。

## 2. 最初に採取してほしい3種類の観測

**OBS-START（画面と環境）**
- コピーの `Vahren.exe` を通常起動し、タイトル画面のスクリーンショットを撮る。
- 画面サイズ、BGM/効果音の音量、表示文字や異常（無表示/黒画面/文字化け）を記録。
- スクリーンショットは `Win + Shift + S` で範囲選択→画像ファイルとして保存。フルスクリーンで失敗する場合は `PrintScreen` 後にペイントへ貼り付け保存。

**OBS-FIRST-TURN（戦略画面）**
- 新しいゲームを開始し、選んだシナリオ名・勢力名・最初のターン番号を控える。
- ターン開始画面のスクリーンショット（勢力資金・支配拠点・ユニットなど見える数値）を採取。
- 可能なら通常操作でターンを1つ進め、その後の同じ項目をスクリーンショットと一緒に控える。
- 行った操作の**順番**も一行ずつ記録する。イベントが発生したら分岐選択と表示結果をそのまま記載。

**OBS-SAVE-LOAD（最重要）**
- 観測用コピーの新しいセーブ枠へ保存。既存の進行データを上書きしない。
- セーブ直前のターン番号・資金・ユニット/Spot数を控える。
- タイトルへ戻り（ゲーム内の正規メニューで可能な場合）、保存データをロードする。
- ロード直後に同じ画面・数値を記録し、エラー・音声/UIの変化も控える。
- 観測用コピー配下で**新しく作られた `.sav` ファイル**を探して、ChatGPTにアップロードするか、観測専用の別フォルダへコピーしてファイル名を教える。存在しなければ「見つからない」で構わない。
- 保存名、日時、ゲーム起動からの大まかな操作順を記録する。時刻依存乱数があるので完全なseed再現を推測しない。

## 3. 写真とファイルの扱い

- スクリーンショットの推奨名: `01_title.png`, `02_scenario.png`, `03_turn0.png`, `04_turn1.png`, `05_before_save.png`, `06_after_load.png`。
- 原作ZIPやゲームEXEのアップロードは不要。まず**画面の画像と観測コピーから作った `.sav` だけ**でよい。
- 画像に個人情報・アカウント名・別アプリの通知が映った場合は、共有前に切り取る。
- セーブファイルを編集/hex書き換えせず、観測用コピーから複写した内容をそのまま共有する。
- 必ず「正常に終わった」「途中で止まった」「未実施」を区別して報告する。動作を確認していない項目をPASSと扱わない。

## 4. 最小限の報告フォーマット

`OBSERVATION_RECORD_TEMPLATE.md` に記入するか、チャットに次を直接送る。

「ゲーム起動できたか／シナリオ・勢力・ターン番号／実際の操作順／画面上の数値・変化／保存できたか／ロードできたか／スクリーンショットとsavの有無」。

**注意**: 本手順は通常のゲーム操作のみ。過去に自動化の安全性チェックで拒否された逆解析や、権限回避をユーザーに代行させるものではない。

これらが揃えば、旧EXEの「観測事実」と新エンジンの現在の「静的実装」の差分を具体的なgolden検証へ進められる。

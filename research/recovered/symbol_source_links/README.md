This is locator resolution only. Each proposal requires an exact B research ID already cited in that dictionary row, the same ID declared in one unique primary authored report's first heading or explicit author ID header within the first 12 lines, and a literal occurrence of the registered symbol VA with only hexadecimal leading-zero normalization. Quoted lines and incidental source/precheck mentions are not accepted as primary declarations. The appended locator names the original source path, declaration/VA lines, recovered destination and SHA256, and retains the entire existing source string intact. No semantic claim, native result, runtime evidence, confidence or READY status is promoted. A literal VA may be in a historical call, range/window or source receipt; this task does not certify that a report substantiates the whole dictionary summary.

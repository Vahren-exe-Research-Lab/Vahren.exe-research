# 従来一覧の外側を確認するための棚卸し

研究ルートの通常ファイル64,793件を、本文を開かず名前・サイズ・更新時刻だけで数えた。従来の1,937目録や選択Markdown一覧は、このフォルダー全体の一覧ではない。ゲーム素材・ビルド成果物・外部ライブラリも含むため、64,793件を研究文書数や未収録研究数とは数えない。Git内部とreparse先は走査しない。個人情報に見える98ファイル名は私用棚卸し内でも識別値に置換し、ここへ実名を掲載しない。全PC・チャットの網羅を示す結果ではない。

目録・選択一覧・台帳の元パスにないMarkdown2,858パスから、名前上の外部依存物・作業コピーを分けると、[139候補](OUTSIDE_PRIOR_MAP_MD_LEADS.tsv)が残る。本文内容・最新SHA・既存保存版との同一性は未確認で、研究内容や取得承認を示す一覧ではない。次の回収では最新台帳・保留と比較し、別名なら既存保存先へつなぎ、実質的に未保存の研究を優先する。物語案・古い案内・開発記録も含み、全件を新発見へ採用することはない。

作業用コピーはファイル名だけで捨てず、[35作業場所のGit状態](ORIGINAL_WORKTREE_METADATA.tsv)を確認した。古い履歴も持つ元リポジトリと現在コピーの既存オブジェクトを読み取り専用で参照し、shallowコピーの履歴境界による誤判定を避けた。32箇所のHEADは現在正本の祖先、3箇所は祖先ではない。[祖先でないコミット](NONANCESTRAL_COMMITS.tsv)はGit上の関係であり、別コミットとして内容が収録済みかどうかは未判定である。さらに4箇所に[追跡ファイルの未コミット変更10パス](TRACKED_CHANGE_PATHS.tsv)がある。未追跡内容をこのGit状態確認で網羅したとは主張しない。

Git取得・設定変更・diff本文の取得・元文書の変更・実行は行っていない。本文保存先、SHA照合、保留・依存・復元確認がまだ全体で揃っていないため、この棚卸しを原本や作業コピーの削除根拠にしない。

公開用の139候補表では、検査パターンに一致したファイル名1件を追加でパスSHAの識別値に置換した。元の名前を認証情報と認定したものではなく、この棚卸しには実名を載せる必要がないためである。これは私用棚卸し時点の98保護名とは別の公開表での最小化であり、元名・本文・内容SHAを取得し直していない。RESTRICTEDの表示は取得先ではなく、未取得・未確認の状態を維持する。

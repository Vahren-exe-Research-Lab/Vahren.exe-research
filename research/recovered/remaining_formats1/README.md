# Remaining formats: historical catalog metadata audit

This bounded audit accounts for the **1,115 `CATALOG_ONLY_UNRESOLVED` entries** in the published 1,937-path catalog at baseline `60bffac58f4b55d56374ab3f15513b468224c5c0`. It inspected only existence, regular-file status, size and modification time at those literal catalog paths. All 1,115 remain present as regular files; nine sizes changed and 1,106 equal the historical size. Equal size does not establish equal bytes. Historical catalog SHA256 values are preserved as historical evidence; **no current original SHA256 was measured and no original body was opened**.

The actual remaining obligation is to triage these different populations, rather than treat 1,115 as unread authored reports:

| Metadata population | Paths | Practical consequence |
| --- | ---: | --- |
| Existing hold metadata | 71 | Preserve prior boundaries: 65 Markdown inventory holds and six exact JSON paths carrying older HOLD21 metadata exclusions. This audit neither lifts those exclusions nor asserts newly acquired native material or an acquisition refusal. |
| Existing other deferral or pending scope | 10 | Consult the exact prior metadata record; this is not a blanket native refusal or approval. |
| Current selected Markdown paths still unreviewed | 30 | These form the overlap with the current 44-path unreviewed Markdown queue. |
| Old Markdown outside current selected folders | 24 | Separate historical review population: eight `exp_research_20261021`, eleven `knowledge`, five `wiki`. All still exist; omission from the current selected-folder map is not disappearance or recovery. |
| Other formats without exact prior review metadata | 980 | Content and origin are unknown. Filename roles offer bounded leads only; this does not authorize reading JSON, text, native-derived dumps, logs or embedded payloads. |

The full old unresolved format totals are JSON 555, text 392, Markdown 129, TSV 20, JSONL 12 and CSV seven. The current 1,600-path inventory instead covers selected Markdown locations (root Markdown and its documented data/evidence/exe/tests/dev_lab/docs/REA report folders). Its 44 unreviewed paths comprise 30 from this unresolved catalog set and 14 absent from the old catalog. Of the 129 old unresolved Markdown paths, 105 are in that map (65 known holds, ten other deferrals, 30 unreviewed), and 24 are outside its selected folders. These denominators are not interchangeable with 1,545 recovery-ledger records, which represent accepted recovery provenance rather than a census of current source versions. This is not a full-PC, all-folder or all-format inventory.

Nine size changes are revision candidates, all Markdown: `MASTER_LEDGER.md`, `data/T013_AI.md`, `data/T024_HAKUSHIN_BATTLE_AI.md`, `dev_lab/docs/CHATGPT_CURRENT_HANDOFF.md`, `evidence/ANALYSIS_LANES_PROTOCOL.md`, `evidence/LANE_B_HANDOFF.md`, `knowledge/README.md`, `knowledge/REF_SAVE_FORMAT.md`, and `knowledge/REF_SAVE_PERSISTENCE.md`. None has an exact source-path recovery-ledger row in this selected set, and none of the 1,115 historical catalog SHA values matches an accepted ledger source SHA. These are metadata comparisons, not current-byte proofs. HANDOFF filenames were statted as authorized literal entries; their bodies were not opened.

`FILENAME_LEADS.tsv` offers eight explicit possible authored receipts/reports (seven JSON, one text), prioritizing small test/readback/provenance records. All eight lack an exact prior deferral record, but authorship, privacy, original/native payload dependencies, held content and usefulness remain unknown. Their filenames do not establish semantic eligibility. A later review requires separate explicit bounded selection and must keep all prior holds. No linked files, assets, scripts, JSON bodies, code, logs, executables, databases, archives or payloads were followed or executed. No reconstruction, runtime result, Golden evidence, READY status or new native claim is produced.

`REMAINING_PATHS.tsv` is the complete selected-path metadata table; `OLD_MARKDOWN_OUTSIDE_CURRENT_MAP.tsv` lists the 24 Markdown scope gaps; `EXISTING_DEFERRAL_PATHS.tsv` links 81 exact paths to prior metadata tables. `COUNTS.tsv`, `EXTENSION_COUNTS.tsv` and `OWNER_COUNTS.tsv` show state, presence, size-change and historical-owner counts. Owner strings are inherited verbatim as catalog attribution, including joint labels, not independently validated authorship.

Paths are relative only. Two auth-like filename records are conservatively replaced by `RESTRICTED/<original-relative-path-SHA256>.txt`; their literal names are not republished. The digest identifies the original relative path, not file content. A consumer must resolve restricted paths through authorized private metadata rather than treating the displayed pseudopath as a fetch target. No originals, shared tables, code or Git state were changed.

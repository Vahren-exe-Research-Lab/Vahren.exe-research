# 旧REA未返却5発言の後続判定

同じ5message IDの短報を、ブラウザで対象発言だけ完全表示して確認した。4件は既存研究の保全・意味整理の状況報告であり、固有の訂正・CALLsite・save/tokenの局所結果は現在の辞書・静的CALL索引・受理済み一次報告へ対応する。1件は既知保留関数の具体契約を含むため、発言全体を保留として本文・部分要約・新辞書項目を作らない。

STATUSは確認した表示文字数・著者commit locator・現在の対応先・限界だけを残す。UI表示はrawMarkdownやサービス保存bytesと異なるため旧記録長809/936/725/802/912とのbytes一致を主張しない。本文SHAは新たに測定・保存していない。報告の13/41/9/12/24という件数や未CURATED/VERIFIED等は当時の著者状況であり現在の不足数ではない。

04/05/06/07H等の複合crosswalkを新たに取得・再構成していない。対応は明記した局所点・保全状況に限り、全旧研究の完全同一性ではない。参照した受理済みsave報告は独立したstream fail-state/bytecount/tokenの局所報告で、保留のshared-stream sentinel/temp-object原本とは別。今回の原作・コード実行は0。

# 表示中も入力保護を整え続ける（Claude 2026-10-31）

ユーザー報告: 一覧の後ろにある原作選択肢（「一覧から選ぶ」）のボタンが押せてしまう。
原因: 同日の「0.25 秒で表示」（show_grace_20261031）で、保護（入力の捕捉）がまだ始まっていない状態で表示すると、表示中（VISIBLE）は捕捉の開始（begin）を呼ばない作りだったため、表を閉じるまで保護が一度も効かなかった。修正前（保護完了まで表示しない）では起きない。
変更: core/hakushin_input_session.c の hkis_after_poll で、猶予表示した表が見えている間（VISIBLE かつ猶予あり）も、準備済みで lease が無ければ begin を呼ぶ。閉じるときは従来どおり end。猶予 0（従来動作）は変化なし。
残る点: 表が出た直後、捕捉が成立するまでの短い間のクリックは原作に届きうる（ユーザー了承済み）。表の窓が前面のときはゲームが非アクティブで入力を読まない。
